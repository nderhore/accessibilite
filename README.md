# Boutik

Site de boutique en ligne pour le cours d'accessibilité.

Il est volontairement non accessible. Pendant le cours, on le corrige ensemble.

## Lancer le site

Ouvrir `site/index.html` dans un navigateur.

## Contenu du dossier site

- `index.html` : accueil
- `inscription.html` : formulaire
- `style.css` : styles
- `bandeau.js`, `accueil.js`, `inscription.js` : scripts

## Publication

Le site est publié sur GitHub Pages à chaque push sur `main`.
